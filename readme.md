# 📊 Sistema de Informes Escolares

![Banner](https://img.shields.io/badge/Sistema%20de%20Informes-orange?style=for-the-badge)

## 🎯 ¿Qué es esto?

Un sistema web simple y efectivo para que estudiantes y padres del una escuela puedan consultar los informes escolares de avances usando solo el DNI del estudiante.

## ✨ Características

- 🔍 Búsqueda rápida por DNI
- 📝 Visualización de calificaciones por etapas
- 📱 Diseño responsivo (se adapta a celulares y computadoras)
- 🎨 Interfaz intuitiva con Material Design

## 👨‍💻 ¿Cómo funciona?

1. Ingresa el DNI del estudiante (solo números, sin puntos)
2. Pulsa el botón "BUSCAR" o presiona Enter
3. Visualiza el informe con las calificaciones por materia
4. Navega entre la primera y segunda etapa con las pestañas

## 🚀 Uso

```bash
# Clonar el repositorio
git clone https://github.com/tu-usuario/ipem298-informes.git

# Abrir index.html en tu navegador
# O súbelo a tu servidor web
```

## 🔄 Datos

Los datos se obtienen desde una API de Google Apps Script conectada a hojas de cálculo con la información académica de los estudiantes.

## 👩‍🏫 Ideal para

- Estudiantes que quieren consultar sus calificaciones
- Padres interesados en el progreso académico
- Profesores que necesitan mostrar información rápidamente
